# Changes in the Revised Manuscript (PRR wt10346)

This file summarizes the major changes made in the revision of "Global
quantum phase estimation with variational quantum circuit neural networks"
in response to the editor and referee reports. All changes are marked in
`paper/manuscript_changes.tex` (generated by latexdiff); the point-by-point
replies are in `paper/response_to_reviewers.tex`.

## 1. Controlled comparisons with objective-matched VQI baselines (Sec. II.B, III.A)

Three VQI variants are now introduced and compared:

- **VQI-local**: the original BMSE-trained baseline from the initial submission.
- **VQI-LinearEst**: trained with the same circular loss as VQ-CNNI, using a linear estimator.
- **VQI-NonParamEst**: trained with the circular loss, using a nonparametric single-outcome readout (the most general single-outcome estimator).

These matched-objective baselines isolate the effect of the training objective
from the effect of nonlinear decoding. Both VQI-LinearEst and VQI-NonParamEst
reduce branch folding relative to VQI-local (confirming that the objective
matters), but their global errors remain substantially above VQ-CNNI, showing
that the residual advantage is attributable to nonlinear decoding of the full
measurement distribution.

## 2. Scaling analysis and noise robustness (Sec. III.E, new)

- **Scaling (N = 4, 6, 8)**: VQ-CNNI's advantage persists as the circuit grows.
  The VQI baselines' full-range performance does not improve with N, while
  VQ-CNNI maintains uniformly accurate global estimation.
- **Noise robustness**: Evaluated under depolarizing gate noise and readout
  bit-flip noise. The learned estimator degrades gracefully under readout noise;
  gate noise is identified as the limiting imperfection. Noise-aware fine-tuning
  is shown to partially recover performance.

## 3. Centralized evaluation protocol (Sec. II.D, new)

All evaluation protocol details (finite-shot vs. exact mode, number of shots,
trials, training seeds, hyperparameters) are now defined once in a dedicated
subsection with a summary table (Table I). All subsequent sections and figure
captions reference this central definition, eliminating redundant and
inconsistent descriptions previously scattered across the manuscript.

## 4. Expanded decoder specification and calibration-inference protocol (Sec. II.A)

- The neural network decoder is now fully specified: architecture
  (N+1 -> 128 -> 64 -> 2 MLP), activation placement (hidden layers only; output
  layer linear and l2-normalized), and parameter count (9666 classical + 6
  quantum for N=8).
- A new paragraph clarifies the calibration-inference distinction: the circular
  loss is used only during a calibration stage with known reference phases; after
  calibration, inference is a single forward pass.

## 5. Activation function analysis (Sec. III.D)

An expanded discussion clarifies that the observed grouping of activation
functions (odd-symmetric vs. asymmetric) is controlled by symmetry rather than
by representational capacity. The analysis shows that Softsign, Arctan, and
Tanh are statistically indistinguishable, while ELU, Softsign-shift, and
Sigmoid degrade global accuracy. The claim is explicitly scoped to this
architecture and training protocol.

## 6. Updated figures and captions

- **Fig. 2**: redesigned to include all three VQI variants alongside VQ-CNNI.
- **Fig. 3**: PCA descriptions made concrete (data matrix construction, color coding).
- **Fig. 6**: new figure with scaling analysis and noise robustness.
- All figure captions standardized to reference the centralized protocol definition.

## 7. Expanded appendix

- **Training algorithm pseudocode** (Algorithm 1): end-to-end joint optimization
  procedure for VQ-CNNI.

## 8. Updated abstract and conclusion

Both the abstract and conclusion now include the controlled baseline comparisons,
scaling analysis, and noise robustness results.
